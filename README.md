# AudioPronóstico

Informe clínico interactivo construido a partir de `calculador_pronostico_hipoacusia.xlsx`.

## Ejecutar localmente

Requiere Node.js 20 o superior.

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

La versión compilada queda en `dist/`. Para previsualizarla:

```bash
npm run preview
```

## Alcance clínico

La aplicación conserva las fórmulas y categorías de los modelos Diao 2025 y Seo 2026 incluidas en la planilla original. Es una herramienta de apoyo y no reemplaza el juicio clínico ni las guías locales.
